## How I think about AI at work

1. Start with the business decision, not the model or output format.
2. Capture durable knowledge outside the chat window.
3. Turn recurring work into explicit workflows and reusable methods.
4. Keep evidence, claims and approvals traceable.
5. Design for adoption and portability rather than dependence on one tool.
